# 🏊 Backend – Resultados en Vivo Natación

Backend en **Flask + PostgreSQL (Supabase)** para mostrar tiempos en vivo, resultados, inscritos y medallero.

---

## 🚀 Deploy automático

Probado en:

- Render.com
- Fly.io
- Railway.app

---

## 📂 Archivos importantes

| Archivo | Descripción |
|--------|-------------|
| `main.py` | Código completo del backend Flask |
| `requirements.txt` | Dependencias |
| `Procfile` | Instrucción de arranque para Gunicorn |
| `runtime.txt` | Versión de Python |
| `.gitignore` | Exclusiones de git |
